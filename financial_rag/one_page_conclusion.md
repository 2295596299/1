## 一句话核心结论
> **同一批财报，具体科目/数字查证与单公司细节适合“建库 (RAG)”，因为财报数据要求 100% 真实且带出处，RAG 能通过精确表格还原与页码追溯消灭幻觉；而全行业大跨度横向对比与宏观梯队统计在纯 RAG 下必然翻车，因为单步检索受限于上下文容量且缺乏跨文档 Map-Reduce 聚合与计算能力。**

## 一、评测实验设置与数据资产

* **数据材料**：A 股白酒行业 **10 家上市公司 2023 年年度报告全文**（贵州茅台 600519、五粮液 000858、泸州老窖 000568、山西汾酒 600809、洋河股份 002304、古井贡酒 000596、舍得酒业 600702、今世缘 603369、迎驾贡酒 603198、口子窖 603589）。
* **切块与索引**：
  * 使用 `pdfplumber` 提取文字与表格，表格按行列完整还原为 Markdown 结构；
  * 每个切块强制封装元数据：`[公司名称, 股票代码, 报告年份, 章节名称, 原始页码, 切块类型]`；
  * 累计切分 **2,971 个结构化切块**（其中表格切块 1,116 个，正文文本切块 1,855 个）；
  * 构建 **BM25（精准词频倒排） + 向量空间（密集语义余弦相似度）双路混合检索**。

## 三、深度归因与实战洞察

### 1. 哪类题答得好？为什么？
* **事实查证与财务细目题（Q1 ~ Q7）**：表现极佳。
  * **原因**：上市公司财报格式高度规范，专业名词（如“研发投入”、“货币资金”、“经销商数量”）词频特征极强。**BM25 能精准锚定目标页码**，结合还原的 Markdown 表格，大模型可以直接“照表宣科”，做到了 **0 幻觉、数字 100% 精确、出处精确到页**。
* **特定战略的定性长文本（Q8）**：表现极佳。
  * **原因**：向量语义检索（Dense Vector）抹平了口语化提问与财报书面语之间的语义 Gap，准确召回了非表格的整段战略论述。

### 2. 哪类题必然翻车？为什么？
* **全景宏观聚合题（Q10）**：典型翻车案例。
  * **根因 1：Context Window 与 Top-K 检索的单步局限**。单次检索 Top-4 或 Top-8 切块，最多容纳 2~3 家公司的表格；无法在单次上下文里装下全部 10 家公司的核心数据，导致“只见树木，不见森林”。
  * **根因 2：朴素 RAG 缺乏计算与 Map-Reduce 聚合能力**。RAG 本质是“局部语义匹配”，它不会主动发起 10 次子查询再做横向排序。要回答全景宏观题，正确的工程路径是 **Agent + Text-to-SQL（先入结构化宽表）** 或 **多智能体 Map-Reduce**，而非硬怼单步检索。
